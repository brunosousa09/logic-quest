LogicQuest

Projeto Aplicado: Logic Quest

Plataforma Gamificada de Microlearning para Fundamentos de Programação em Python, focada em combater a evasão nos primeiros períodos de Sistemas de Informação na UAST-UFRPE.

1. O Problema e a Justificativa

A taxa de evasão nas disciplinas introdutórias de programação é um desafio acadêmico histórico. O principal obstáculo cognitivo para os ingressantes é a abstração. Conceitos como alocação de memória, laços de repetição infinitos e o escopo de retorno de funções são invisíveis no console tradicional.

O Logic Quest ataca essa barreira traduzindo o código abstrato (Python) em mecânicas visuais tangíveis (Glassmorphism). O erro deixa de ser uma linha vermelha no console e passa a ser uma "quebra de vidro" ou um "curto-circuito" visual na interface, fixando o aprendizado por consequência imediata.

2. A Jornada Pedagógica (Os 4 Mundos)

Mundo 1: Berçário de Dados

Ensina tipagem estrita e dinâmica. O aluno manipula blocos de dados reais e os insere em contêineres de memória. Erros de tipo causam rachaduras visuais no sistema.

Mundo 2: Labirinto do Tempo

Foco em controle de fluxo (`while`). O aluno é levado a cometer o erro clássico de esquecer o incremento (`i += 1`), o que gera um "Memory Leak" simulado, travando a tela de propósito.

Mundo 3: Buraco Negro (Funções)

Desmistifica a diferença entre exibir e retornar. O aluno aprende que `print()` gera apenas fumaça visual, enquanto `return` cria conexões de dados reais entre sistemas.

Mundo 4: Big Boss (Legacy)

O exame final. Um dashboard hospitalar quebrado. O aluno deve refatorar múltiplos blocos de código simultaneamente para reviver os gráficos de produtividade em tempo real.

3. Viabilidade Técnica

Camada Tecnologia (Full-Stack Solo) Propósito
Frontend UI/UX React, Tailwind CSS Geração de interface Liquid Glass interativa e responsiva via componentes.
Backend & Banco de Dados Django, PostgreSQL API RESTful robusta para controle de estados, progresso do aluno e persistência segura dos dados da plataforma.
Motor Gamificado Integração React (DOM) Controle de toques dinâmicos, drag/drop e simulação renderizada de falhas (glitches).
